Processing pipeline

Upload to evidence in four steps.

Images run once; video is sampled frame-by-frame, re-annotated and re-encoded as MP4 so CPU Spaces stay responsive.

1

Upload

Drop an image or a video clip into either the all-models tab or a single model.

2

Detect

Loaded models run inference — YOLO draws boxes, the CNN predicts a vehicle class.

3

Annotate

Boxes, labels and confidence are burned onto the frame; video is re-encoded to MP4.

4

Export

Download a CSV with one row per detection: model, class, confidence and box.
